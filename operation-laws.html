运算律字母公式举例
加法交换律a + b = b + a45+38 = 38+45
加法结合律(a+b)+c = a+(b+c)118+75+82：先算118+82
乘法交换律a × b = b × a6×25 = 25×6
乘法结合律(a×b)×c = a×(b×c)25×4×13：先算25×4
乘法分配律a×(b+c) = a×b + a×c102×45 = 100×45+2×45
🧮 运算顺序：有小括号先算小括号，有中括号先算中括号（小括号在里面，先算它）；先乘除、后加减；同级运算从左往右。
🎯 分配律口诀：乘进去，每人都要乘到，一个都不许漏！a×(b+c) = a×b + a×c，减法也行：a×(b−c) = a×b − a×c。
🔍 反着用（提取公因数）：a×b + a×c = a×(b+c)。看见相同的数（公因数）就把它提出来，剩下的加在括号里。
⚠️ 最大易错点：结合律是"只有乘（或只有加）时换括号"；分配律是"乘法去喂加法"。见到 125×(8×6) ≠ 125×8+125×6，别混！
